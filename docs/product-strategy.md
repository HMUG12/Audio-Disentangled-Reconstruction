# ADR 产品战略：定位 · 用户 · 生态

> 2026-08-16 与三期规划配套。回答三个问题：给谁用、是什么、怎么长。

## 一、产品定位（一句话）

**ADR = 本地音色资产工作站**：录一段声音，存成资产，说话唱歌流式随取随用——全部在你自己电脑上，8GB 显卡即可。

不做"又一个云端 TTS 服务"，做**语音界的 Stable Diffusion WebUI**：
本地、可训练、可扩展、低配友好、资产归用户所有。

### 三条不妥协的原则

1. **声音是资产，不是一次性输入** — 档案库 + 增量续练 + 说话唱歌通用（对同产品的核心差异）
2. **质量自己说了算** — ERes2Net/ASR 门禁内置，产品自带"好不好的答案"
3. **低配不是降级版，是主战场** — 8GB/三卡 Win 是一等公民（大厂产品都在往云端和旗舰卡跑）

### 与替代方案的错位

| 用户选择 | 痛点 | ADR 回答 |
|---|---|---|
| ElevenLabs 等云服务 | 按月付费、声音上传云端（生物特征！）、不能唱歌 | 本地、一次拥有、说话+唱歌 |
| GPT-SoVITS 官方 WebUI | 只说话、工具链割裂、配置劝退 | 统一档案、一条流水线、一键安装 |
| DiffSinger/ACE | 固定歌手或封闭商业 | 你的音色唱歌（D1 转换链） |

### 第三条原则之外的第四支柱：自研架构是长线武器

**ADR-2 架构的独特牌（行业独家设计）**：单模型统一双模——TTS 和 SVS 是同一模型的两个头（mode embedding + 统一 FlowDecoder），不是"说话引擎+唱歌引擎"胶水拼装。当前保底形态（GSV+DiffSinger 拼接 + RVC 转换链）恰恰暴露了拼装的代价：音色统一靠事后转换。自研做成之日，"一份资产说话唱歌"就是原生的。

**机制创新——自研擂台（产品内置挑战者）**：ADR-2 每次迭代自动与保底引擎跑同一组门禁（CER + ERes2Net 相似度 + 延迟），达标即自动晋升默认引擎，不达标继续当影子。架构竞争变成自动过程，不是一次性豪赌。这也让用户无感地伴随自研成长。

**ADR-2 架构资产清单**（已验证可用的部件）：
- 统一 FlowDecoder（mel 空间条件流，精确 NLL 免 GAN，原生支持流式增量解码）
- MoE+SSM 缝合块（CP2：角色/知识/情感专家路由，14M+4M 参数冒烟通过）
- 高斯随机时长预测 + MAS 对齐（端到端韵律学习）
- F0 旋律注入逐帧条件（唱歌头的原生接口）
- 8GB QLoRA 原生设计（0.3B 级 ~0.8GB 实测）

**当前差距（诚实）**：自由采样 CER 1.157 不可懂、声码器电音感（BigVGAN 语音域 vs 歌声域差，根因已定位）。自研线下一步见三期 C5。

## 二、用户定位（谁先谁后）

### P0 首发人群：中文个人内容创作者
短视频配音、有声内容、直播切片二创。**要的是"我的声音批量产出"**。
- 核心场景：录 7 秒 → 存档案 → 天天用 → 30 分钟微调升级 → 越用越像
- 为什么是他们：对"像不像"最敏感（我们门禁正好量化），对付费云服务最抗拒

### P1 扩展人群：虚拟歌手圈 / 二创音乐人
Vocaloid·ACE·DiffSinger 社区本来就在拼工具链。**"让我自己的声音唱歌"是未被满足的需求**（ACE 只有官方歌手）。
- D1 转换链直接命中

### P2 长尾人群：小工作室 / 隐私敏感场景
本地化部署刚需（儿童内容、医疗配音、内部培训）。声音不出内网是硬约束。

### 明确不服务（现在）
- 要手机端/App 的泛用户（我们是 Windows 工作站）
- 要云端 API 规模调用的企业（没有服务层）
- 英文为主用户（中文优化优先）

## 三、生态（怎么长大）

### 生态三件套

1. **引擎可插拔**：ADRBackbone 接口（M8.6 已定型）——GPT-SoVITS/DiffSinger 是前两个引擎，第三方可接 IndexTTS/CosyVoice2/未来自研。**ADR 不做引擎垄断，做引擎之上的资产层和工作流**
2. **音色档案开放格式**：`data/voices/<name>/`（ref.wav + meta.json + 权重指针）——可读、可备份、可分享
3. **质量门禁即标准**：ERes2Net 分数成为音色包的"营养成分表"——分享的档案自带相似度评分，社区有共同语言

### 增长飞轮

```
创作者用 ADR 产出内容 → 被问"这声音怎么做的" → 新用户
→ 分享音色档案/训练配方 → 档案越攒越多 → 产品越用越值
```

### 合规红线（生态能不能活的前提）

声音克隆 = 深度伪造风险面。**必须内置**：
- 首次启动明示：仅克隆本人或获授权的声音
- 音色档案 meta 带 `consent` 字段（本人声明/授权声明）
- 分享功能默认要求 consent=true
- 文档显著位置放法律提示（民法典人格权、深度合成规定）

## 四、与三期技术计划的挂接

| 战略 | 依赖的技术项 |
|---|---|
| 声音是资产 | C3 增量持久化、D1 歌声转换链 |
| 质量自己说了算 | D2 门禁闭环、A5 分数进 UI |
| 低配主战场 | C6 三卡、C7 资源压缩、A4 一键安装 |
| 生态可插拔 | 引擎接口固化 + 文档（A4 一并做） |

**北极星指标建议**：用户档案的"7 天复用率"（建档后一周内再次使用的比例）——资产型产品的命门是复用，不是首次惊艳。
