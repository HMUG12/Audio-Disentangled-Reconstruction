以下设置决定本地引擎的启动方式（数据目录 / 推理设备 / 线程上限 / 资源上限在引擎启动那一刻生效），随时可在「启动器 → 设置」里修改。全部只保存在本机，不外发。

① 版本与模型存放位置

      
当前安装包：通用包（运行时自动识别 NVIDIA / Intel 显卡并选择 CUDA 或 CPU）。按显卡型号单独裁剪的专用优化包（N 卡 / I 卡）本版本未单独发布，安装时无需选择。

      
模型与权重存放位置：检测中…

      

        
        
      

      
⑨ 检查模型：只核对本机文件是否齐全，不联网、不下载。缺失项会列出文件名，可手动补齐后再次检查。

      
② 自定义导入权重：本向导不提供文件选择框（权重按 GPT-SoVITS 目录结构存放）；把 .ckpt / .pth 放进上面对应目录后，在「启动器 → 模型」里切换生效。

⑤ 线程协同与 GPU 占用：显存上限按总显存比例限制本进程占用，达到上限即报显存不足（不会把整机拖进交换）；显卡占用率百分比上限由系统任务管理器控制，本版本不代管。

      
⑥ 内存（RAM）硬上限本版本未提供（由操作系统统一管理），后续版本补齐。

      
⑦ 强度档位会同时调整调度并发上限与跨请求合批开关，不是装饰性选项；训练与推理共用同一设备，不提供单独的「训练模式」开关。
